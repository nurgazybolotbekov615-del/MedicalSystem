# MedicalSystem
Консольное приложение для поликлиники: выдача справок (083, 086/У, санитарная книжка) и отправка пациентам в Telegram.

## Возможности
- выбор типа справки и группы крови
- отправка справки пациенту в Telegram
- журнал выданных справок и чек за смену

## Запуск
    $env:TELEGRAM_BOT_TOKEN="токен_бота"
    dotnet run
